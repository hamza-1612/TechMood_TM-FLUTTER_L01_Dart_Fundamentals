# نظام إدارة الطلاب

برنامج بسيط بلغة **Dart** يعمل في الطرفية لإدارة بيانات مجموعة من الطلاب. يوضّح أساسيات Dart والبرمجة كائنية التوجه (OOP) من خلال إنشاء صنف `Student`، وتخزين الكائنات في قائمة، والتعامل مع إدخال المستخدم.

## فكرة المشروع

يمثّل كل طالب باستخدام الصنف `Student`، وتُحفظ بياناته كالتالي:

- الاسم
- العمر
- التخصص
- الدرجة

يحتوي البرنامج على بيانات تجريبية، ثم يطلب إدخال طالب جديد ويضيفه إلى القائمة. بعد ذلك يعرض بيانات الطلاب وحالة كل طالب، ويسمح بالبحث عن طالب باستخدام اسمه.

## الوظائف

- إنشاء كائنات طلاب باستخدام constructor يحتوي على معاملات `required`.
- تخزين الطلاب في `List<Student>`.
- طباعة بيانات كل طالب.
- تحديد النجاح أو الرسوب باستخدام `if`؛ درجة النجاح هي **50 من 100**.
- البحث عن طالب بالاسم، مع تجاهل اختلاف الأحرف الكبيرة والصغيرة.
- التحقق من الدرجة باستخدام `try/catch`؛ يجب أن تكون رقمًا بين 0 و100. عند إدخال قيمة غير صحيحة، يطلب البرنامج الدرجة مجددًا.
- استخدام `??` لتوفير قيمة بديلة إذا لم يصل إدخال من الطرفية.

## المتطلبات

- تثبيت **Dart SDK** على الجهاز.
- التأكد من أن أمر `dart` متاح في الطرفية.

للتحقق من التثبيت، شغّل:

```bash
dart --version
```

## طريقة التشغيل

1. افتح الطرفية داخل مجلد المشروع الذي يحتوي على `main.dart`.
2. شغّل البرنامج بالأمر:

```bash
dart run main.dart
```

إذا كان إصدار Dart لديك لا يدعم `dart run`، يمكنك تشغيله هكذا:

```bash
dart main.dart
```

## استخدام البرنامج

رسائل الطرفية مكتوبة بالإنجليزية لتفادي مشاكل عرض اتجاه العربية في بعض إصدارات CMD. أدخل الاسم والعمر والتخصص والدرجة عندما يطلبها البرنامج.

- الدرجة من 0 إلى 100 تُقبل.
- الدرجة الأقل من 50 تعني **Failed**، والدرجة 50 أو أعلى تعني **Passed**.
- إذا كانت الدرجة نصًا أو خارج هذا النطاق، ستظهر رسالة خطأ ويُطلب إدخالها مجددًا.
- قد تظهر الأسماء أو التخصصات المكتوبة بالعربية باتجاه غير صحيح في CMD؛ استخدم Windows Terminal أو أدخلها بالإنجليزية إذا واجهت ذلك.

أخيرًا، يعرض البرنامج بيانات الطلاب ويطلب اسمًا للبحث عنه.
